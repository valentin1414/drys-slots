# Андрей Royale — Skyrim-издание чужого подарка

Шуточные слоты на день рождения Андрея. Зачёркнутое старое имя и кривые наклейки намеренные. Версия для компьютера, без отдельной адаптации под телефоны.

## Что внутри

- Все 10 фотографий из папки «фотки андрея».
- Девять фраз проигрыша в заданном порядке. Стартовый баланс 8 000 условных тенге, ставка 800 ₸. Фотографии выпадают случайно и могут повторяться. Три одинаковые дают джекпот «Дары Девяти» — 4 000 ₸ (шанс 12% за прокрутку), то есть ещё пять ставок. При джекпоте появляется отдельная золотая полоса в духе Dark Souls. Счётчик показывает оставшиеся прокрутки.
- Коллекция начинается с 0/10: до выпадения на остановившихся барабанах карточка чёрная, её нельзя открыть. После выпадения карточка появляется и открывается крупно по нажатию. Гарантированных карточек нет: полной коллекции может не хватить даже после всех прокруток. Если денег на ставку не осталось, появляется окно «Молодец, давай заново» с фотографией и кнопкой перезапуска. Перезапуск очищает коллекцию и возвращает 8 000 ₸.
- Как только открыты 10/10 карточек, появляется окно с полной колодой и кнопкой «Продолжить». После нажатия — выход Продавца говна: силуэт, дым, проявление лица, ударная надпись и звук, затем бой. Выход длится около 6,6 секунды; его можно пропустить кнопкой или Escape. Коллекцию можно собрать раньше десятой прокрутки.
- Каждая фотография — отдельная боевая карточка. В бою наведение показывает способность, эффект и оставшиеся применения. Одинаковые способности на разных карточках имеют отдельные заряды.
- Андрей: 100 HP. Босс: 200 HP. После заклинания босс отвечает. «Ням-ням»: 18 урона без ограничений; «Оба колена»: 30 урона и ослабление следующего ответа, одно применение у карточки; «ЕБАТЬ😂😂😂»: 45 урона, одно применение; «Выздоравливай»: до +40 HP, два применения.
- После поражения можно повторить бой с полной колодой, сохранив собранные картинки. После победы открывается отдельный экран с воином на закате: «Победив Продавца говна, ты достиг чекпоинта. Очередной цикл пройден, впереди новые свершения. Следующая цель — Чёрный пёс и 6 Б».
- «Начать заново» в слотах и «Сыграть заново» после победы начинают весь путь с пустой коллекцией.
- Серебряные рамки, северные горы, туман, атмосфера Skyrim. Фоновый рисунок и эмблема нарисованы для проекта; звуки синтезируются в браузере.

## Открыть на компьютере

Сайт работает даже при открытии `index.html` двойным щелчком. Для локального сервера запустите `ЗАПУСТИТЬ-САЙТ.cmd` из родительской папки. Адрес: http://127.0.0.1:4173/ . Пока сервер запущен, сайт доступен на этом компьютере.

## Обновить уже опубликованный сайт

1. Распакуйте свежий архив `drys-slots-github.zip` в отдельную папку.
2. Откройте существующий репозиторий [valentin1414/drys-slots](https://github.com/valentin1414/drys-slots), ветку **main**, и нажмите **Add file → Upload files**.
3. Перетащите **всё содержимое распакованного архива**, включая все файлы в корне и папку **assets целиком**. Сам ZIP и внешнюю папку загружать не нужно: `index.html` должен лежать прямо в корне репозитория. Файлы с теми же путями обновятся, новые добавятся.
4. Сохраните изменения в **main** кнопкой **Commit changes**. Заранее удалять старые файлы и заново настраивать Pages не требуется.
5. Дождитесь завершения публикации в разделе **Actions**, затем откройте сайт по прежней ссылке и обновите через **Ctrl+F5**.

## Опубликовать через GitHub Pages впервые

1. Войдите в GitHub под аккаунтом `valentin1414`.
2. Нажмите **+ → New repository**. Назовите его, например, `drys-slots`.
3. Выберите **Public**, включите **Add README**, нажмите **Create repository**. На GitHub Free для Pages нужен публичный репозиторий: исходники и фотографии будут доступны всем.
4. Откройте **Add file → Upload files**. Загрузите **всё содержимое этой папки**, включая `index.html`, все файлы CSS, `app.js`, `slot-engine.js`, `battle-engine.js`, `battle-ui.js`, `boss-intro.js`, `.nojekyll` и **папку assets целиком**. Можно перетащить их в браузер из Проводника. В корне репозитория должен лежать сам `index.html`, а не ещё одна папка `artem_dr-main`.
5. Нажмите **Commit changes** и сохраните файлы в ветку **main**.
6. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
7. Выберите ветку **main**, папку **/(root)**, затем **Save**.
8. Дождитесь публикации, обычно несколько минут, иногда до 10. На этой же странице появится **Visit site**. При названии `drys-slots` ссылка будет `https://valentin1414.github.io/drys-slots/`.
9. Откройте ссылку, проверьте фотографии и прокрутку. Эту ссылку можно отправить Андрею; ваш компьютер для работы опубликованного сайта не нужен.

Для обновления снова загрузите изменённые файлы по тем же путям и нажмите **Commit changes**. GitHub Pages обновит сайт автоматически. Если показывается старая версия, обновите страницу с **Ctrl+F5**.

Папки `backups`, `.preview`, исходные «фотки андрея» и файлы локального сервера в репозиторий загружать не нужно. Публикуется только содержимое `artem_dr-main`.

Документация GitHub: [создание сайта](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [настройка публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
